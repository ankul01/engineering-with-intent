# Templates

Reusable templates for documenting architecture decisions and engineering practices.

## Available Templates

### Decision Page Template
For documenting architecture decisions with context, constraints, options, and trade-offs.
[View Template →](/templates/decision-template)

### Operating System Playbook Template
For documenting repeatable engineering practices that teams can adopt.
[View Template →](/templates/playbook-template)

## When to Use Each

| Template | Use When |
|----------|----------|
| Decision Page | Making an architecture or technical decision that affects multiple teams or has long-term implications |
| Playbook | Documenting a repeatable practice that teams should follow consistently |

## Tips

1. **Copy the template** — Don't edit the template itself
2. **Fill in all sections** — Even if brief, each section adds value
3. **Link to evidence** — Reference data, discussions, or prior decisions
4. **Get review** — Share with stakeholders before finalizing
5. **Keep it updated** — Decisions and practices evolve
