# Decision Templates

Reusable formats for documenting architecture decisions.

## Available Templates

- **[Decision Page Template](/templates/decision-template)** — Full template for documenting architecture decisions with constraints, options, and trade-offs
- **ADR (Architecture Decision Record)** — Lightweight decision record format
- **Tradeoff Matrix** — Structured comparison of options

## When to Use Each

| Template | Use When |
|----------|----------|
| Decision Page | Complex decisions with multiple stakeholders |
| ADR | Quick decisions that need a paper trail |
| Tradeoff Matrix | Comparing 3+ options on 5+ dimensions |
