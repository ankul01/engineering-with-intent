## Pattern Categories

| Pattern | When to Use |
|---------|------------|
| **Sliding Window** | Contiguous subarrays |
| **Two Pointers** | Sorted arrays, pairs |
| **Binary Search** | Sorted data, search space |
| **BFS** | Shortest path, level order |
| **DFS** | All paths, tree traversals |
