## Leadership Levels

| Level | Scope | Key Skills |
|-------|-------|-----------|
| **Tech Lead** | Project/squad level | Technical excellence, mentoring, delivery |
| **Engineering Manager** | Team level (5-8 engineers) | People management, hiring, performance |
| **Senior Manager** | Multiple teams | Strategy, org design, stakeholder management |
| **Director+** | Organization level | Vision, executive influence, business acumen |

## Core Leadership Competencies

### Setting Direction
- Defining vision and strategy
- Prioritization and tradeoffs
- Communicating the "why"

### Building Teams
- Hiring great people
- Developing talent
- Creating psychological safety
- Building diverse, inclusive teams

### Driving Results
- Execution excellence
- Accountability and ownership
- Removing blockers
- Sustainable pace

### Collaboration
- Cross-functional partnership
- Influence without authority
- Stakeholder alignment
- Conflict resolution

### Communication
- Executive presence
- Difficult conversations
- Written communication
- Listening and empathy

## Leadership Philosophy

### The Leader's Job

```
┌─────────────────────────────────────────────────────────────┐
│                    The Leader's Job                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. Set Direction                                            │
│     - Where are we going?                                   │
│     - Why does it matter?                                   │
│                                                              │
│  2. Build the Team                                          │
│     - Hire great people                                     │
│     - Develop and retain talent                             │
│                                                              │
│  3. Remove Obstacles                                        │
│     - Clear blockers                                        │
│     - Secure resources                                      │
│     - Shield from distractions                              │
│                                                              │
│  4. Create Environment for Success                          │
│     - Psychological safety                                  │
│     - Clear expectations                                    │
│     - Recognition and growth                                │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### Manager vs Leader

| Manager | Leader |
|---------|--------|
| Focuses on systems | Focuses on people |
| Asks "how" and "when" | Asks "what" and "why" |
| Maintains | Develops |
| Relies on control | Inspires trust |
| Short-term view | Long-term vision |

*Great engineering leaders do both.*
