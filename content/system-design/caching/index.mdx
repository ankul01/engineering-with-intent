## Caching Patterns Quick Reference

| Pattern | Use Case |
|---------|----------|
| **Cache-Aside** | Application manages cache, most flexible |
| **Read-Through** | Cache loads data on miss |
| **Write-Through** | Writes go to cache and DB synchronously |
| **Write-Behind** | Writes to cache, async to DB |
