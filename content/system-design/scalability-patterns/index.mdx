## Scaling Strategies

| Strategy | When to Use |
|----------|------------|
| **Vertical** | Quick fix, limited ceiling |
| **Horizontal** | Linear scaling, more complex |
| **Caching** | Read-heavy workloads |
| **Sharding** | Data too large for one machine |
| **CQRS** | Different read/write patterns |
