# Leadership Learning

Interview preparation repository for senior engineering and engineering leadership roles.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) with App Router
- **Documentation Theme**: [Nextra 4](https://nextra.site/) Docs Theme
- **Content**: MDX (Markdown with JSX support)
- **Deployment**: GitHub Pages (Static Export)

## Focus Areas

- Platform thinking
- Scalability
- Risk & Compliance
- Stakeholder Alignment
- Execution Excellence
- Business Impact

## Getting Started

### Prerequisites

- Node.js 20+
- npm or pnpm

### Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000/leadership-learning](http://localhost:3000/leadership-learning) to view the site.

### Build

```bash
# Build for production
npm run build
```

The static output will be in the `out/` directory.
